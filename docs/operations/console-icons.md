# Console icons

Project marks identify the applications they link to. Assets are local files under
`docker/caddy/console/icons/`, the same files as the Platform Edge console, so rendering
does not contact third-party image services. Original project trademarks remain with
their respective owners.

- Gateway mark: an original SVG from platform-edge.
- LiteLLM: https://github.com/BerriAI/litellm/blob/main/litellm/proxy/swagger/favicon.png
- Langfuse: https://github.com/langfuse/langfuse/blob/main/web/public/icon.svg
- RustFS: https://github.com/rustfs/console/blob/main/app/icon.svg
- PostgreSQL, ClickHouse, Valkey, Caddy and Prometheus (the exporters): https://github.com/homarr-labs/dashboard-icons/tree/main/svg (postgresql.svg, clickhouse.svg, valkey.svg, caddy.svg, prometheus.svg).

Icons are decorative; adjacent text supplies the accessible link name.

GitHub mark: https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg (MIT; see ../licenses/octicons.txt), inlined in `index.html` so it takes the text colour.
